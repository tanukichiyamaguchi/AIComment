# assets/

コメントページ生成に使うアセットファイルを置くディレクトリ。

| ファイル | 用途 | 取得方法 |
|---|---|---|
| `jissen_kun.png` | じっせん君キャラクター画像。コメントページの右下に配置される | リポジトリにコミット（このディレクトリにアップロード） |
| `NotoSansJP-Regular.ttf` | 本文フォント | 初回実行時に自動ダウンロード（`.gitignore` 済み、コミット不要） |
| `NotoSansJP-Bold.ttf` | 見出しフォント | 同上 |

## `jissen_kun.png` について

- 背景透過の PNG 推奨（`pdf_creator.py` は `mask="auto"` で透過を扱う）
- コメントページ右下に 35mm × 35mm で描画される（縦横比は維持）
- このファイルが存在しない場合、画像なしでコメントページが生成される（警告ログのみ）
